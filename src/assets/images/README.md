# Images Folder

Place your real portfolio images here for production use:

- `hero.png` or `hero.jpg` — Your main professional hero photo
- `gallery-1.png` / `gallery-2.png` / `gallery-3.png` — Your 3 professional gallery photos
- Any additional gallery images

Then update the paths in `src/data/portfolioData.js` (or re-save via the Onboarding Wizard).

## Recommended sizes
- Hero image: 800x1000px (portrait, high quality)
- Gallery images: 1200px wide minimum
- Format: JPG or PNG (optimize for web)
