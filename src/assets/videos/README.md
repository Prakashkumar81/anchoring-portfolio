# Videos Folder

Place your real portfolio videos here for production use:

- `showreel.mp4` — Your main cinematic showreel video
- `highlight-1.mp4` / `highlight-2.mp4` / `highlight-3.mp4` — Your 3 highlight videos

Then update the paths in `src/data/portfolioData.js` (or re-save via the Onboarding Wizard).

> **Note:** Local video files are best hosted on YouTube/Vimeo for the React Player to stream reliably. You can paste a YouTube/Vimeo URL in the wizard or here. For local files, use `.mp4` (H.264) format.
